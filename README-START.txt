║          CaptchaSolve — How to Start                 ║
╚══════════════════════════════════════════════════════╝

▶  EASIEST WAY
   Double-click:  start.bat
   That's it. A green terminal window opens.

▶  MANUAL WAY (Command Prompt / PowerShell)
   1. Open Command Prompt or PowerShell
   2. Type:  cd D:\captcha-solver
   3. Type:  node index.js

▶  ONCE RUNNING — open these in your browser:
   http://localhost:3000          ← API Docs
   http://localhost:3000/guide    ← Full Guide
   http://localhost:3000/worker   ← Worker Dashboard
   http://localhost:3000/admin    ← Admin Panel

▶  TO STOP
   Press Ctrl+C in the terminal window
   (or close the terminal window)

▶  REQUIREMENTS
   Node.js v22 or higher must be installed.
   Check: open CMD and run  node --version
   Download from: https://nodejs.org
