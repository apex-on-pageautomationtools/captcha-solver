How It Works

1

Submit — Your client POSTs the CAPTCHA (image or reCAPTCHA params) to /in.php, receives a task ID.

2

Queue — Task stored in SQLite, pushed to online human workers via WebSocket in real time.

3

Solve — A worker sees the challenge in their browser dashboard, solves it and submits the answer.

4

Poll — Your client polls GET /res.php?id=TASK_ID every 5s until OK|TOKEN is returned.

5

Use — Inject the token into the form and submit. If wrong, report it for a refund.

API Endpoints

POST /in.php

Submit a CAPTCHA task. Returns OK|TASK_ID on success.

ParamTagDescription
keyREQYour API key
methodOPTbase64 / userrecaptcha / hcaptcha / turnstile (default: base64)
bodyREQ*Base64-encoded image (image CAPTCHA only)
googlekeyREQ*Site key (reCAPTCHA/hCaptcha/Turnstile)
pageurlREQ*Page URL where the CAPTCHA is (token types)

# Image CAPTCHA
curl -X POST http://localhost:3000/in.php \
  -d "key=YOUR_API_KEY&method=base64&body=BASE64_IMAGE"
# → OK|a3f9c2b1e4d8

# reCAPTCHA v2
curl -X POST http://localhost:3000/in.php \
  -d "key=YOUR_KEY&method=userrecaptcha&googlekey=SITE_KEY&pageurl=https://example.com"
GET /res.php

Poll result, check balance, or report a bad answer.

ParamTagDescription
keyREQYour API key
actionOPTget (default) / getbalance / reportbad
idREQ*Task ID returned by /in.php

# Poll (call every 5s)
curl "http://localhost:3000/res.php?key=YOUR_KEY&action=get&id=a3f9c2b1e4d8"
# → CAPCHA_NOT_READY  (keep polling)
# → OK|03AGdBq25...   (done!)

# Check balance
curl "http://localhost:3000/res.php?key=YOUR_KEY&action=getbalance"
# → 9.9860

# Report wrong answer (refund)
curl "http://localhost:3000/res.php?key=YOUR_KEY&action=reportbad&id=a3f9c2b1e4d8"

Python / Node.js Client Example

# Python example (drop-in 2captcha replacement)
import requests, time

API = "http://localhost:3000"
KEY = "YOUR_API_KEY"

def solve_image(base64_img):
    r = requests.post(f"{API}/in.php", data={
        "key": KEY, "method": "base64", "body": base64_img
    })
    task_id = r.text.split("|")[1]

    for _ in range(24):       # poll up to 2 min
        time.sleep(5)
        r = requests.get(f"{API}/res.php", params={
            "key": KEY, "action": "get", "id": task_id
        })
        if r.text.startswith("OK"):
            return r.text.split("|")[1]
    raise TimeoutError("Not solved in time")
