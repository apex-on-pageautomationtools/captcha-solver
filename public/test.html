③ Or test with curl / Python

Use the real reCAPTCHA flow end-to-end from your terminal:

# 1. Submit reCAPTCHA task
curl -X POST "http://localhost:3000/in.php" \
  -d "key=YOUR_API_KEY&method=userrecaptcha&googlekey=6LeIxAcTAAAAAJcZVRqyHh71UMIEGNQ_MXjiZKhI&pageurl=http://localhost:3000/test"
# → OK|a3f9c2b1e4d8abc7

# 2. Poll every 5s until OK|TOKEN
curl "http://localhost:3000/res.php?key=YOUR_API_KEY&action=get&id=a3f9c2b1e4d8abc7"
# → CAPCHA_NOT_READY  (keep polling)
# → OK|03AGdBq25...   (worker solved it!)

Or use captchasolve.py (drop-in 2captcha client):

from captchasolve import CaptchaSolver

solver = CaptchaSolver("YOUR_API_KEY", api_url="http://localhost:3000")
token  = solver.recaptcha(
    "6LeIxAcTAAAAAJcZVRqyHh71UMIEGNQ_MXjiZKhI",
    "http://localhost:3000/test"
)
print("Token:", token[:30] + "…")

④ How the worker dashboard embeds this page

When a worker gets a reCAPTCHA task pointing to http://localhost:3000/test, their dashboard automatically shows an embedded iframe of this page. They solve it here, and the token is sent back via postMessage — no copy/paste needed.

Worker solves CAPTCHA in iframe →
window.parent.postMessage({type:'captcha_token', token:'03AGdBq25…'}, '*')
→ Worker dashboard auto-fills the token → Worker clicks Submit ✓
